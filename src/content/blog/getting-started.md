> 初始化示例文章，请在正式发布前替换为你的真实内容。

## 写下你的第一篇文章

在 `src/content/blog/` 新建 Markdown 文件，补充标题、摘要、发布日期和唯一 slug。

## 让内容保持简单

文章可以包含段落、列表、引用和代码。不需要修改页面组件即可添加新内容。

- 使用稳定的 slug 作为文章地址。
- 发布前检查日期、图片与链接。
- 将 `draft` 改为 `false` 后重新构建。

## 代码示例

const message: string = 'Hello, Personal Web!';
console.log(message);
