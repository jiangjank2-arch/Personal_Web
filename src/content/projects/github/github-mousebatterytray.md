## 项目简介

轻量 Windows 鼠标电量工具，在通知区域显示电量，并根据最近产生输入的鼠标切换设备。

- 资料读取日期：2026-10-28

## 功能与说明

- 在 Windows 通知区域显示电池图标和电量数字。
- 识别最近产生输入的鼠标；支持手动刷新和固定设备。
- 设备未向 Windows 提供电量时显示问号，不沿用其他连接方式的旧电量。
