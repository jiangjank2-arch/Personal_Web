## 项目简介

基于 Java Swing、MySQL 和 JDBC 的教务管理系统，支持管理员、教师、学生三种角色。

## 功能与说明

- 管理员维护学生、教师、课程、成绩与账号信息。
- 教师查看所授课程并录入成绩，学生查看个人成绩与基本信息。
- 通过 JDBC 连接 MySQL，提供数据库初始化脚本和本地启动说明。
